# DigitalMind — Comprends, Teste, Détoxifie

DigitalMind est une plateforme web interactive dédiée à la sensibilisation contre la cyberdépendance et l’addiction aux réseaux sociaux.

Le projet aide les utilisateurs à comprendre :
- comment les algorithmes manipulent l’attention,
- comment la dopamine influence le comportement numérique,
- et comment retrouver un équilibre sain grâce à des outils de digital detox.

---

## Fonctionnalités

### Simulateur d’algorithme
L’utilisateur devient l’algorithme d’un réseau social et choisit les contenus à afficher afin de maximiser l’engagement.

### Cerveau dopaminergique interactif
Visualisation des zones du cerveau activées par :
- les notifications,
- les likes,
- le scroll infini,
- les recommandations vidéos.

### Test de cyberdépendance
Questionnaire interactif permettant d’obtenir :
- un score de dépendance,
- une analyse des risques,
- des conseils personnalisés,
- un profil détaillé avec graphiques.

### Outils de Digital Detox
- Minuteur Pomodoro
- Défis quotidiens
- Suivi de progression
- Suggestions d’activités hors écran
