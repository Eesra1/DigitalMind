# DigitalMind
DigitalMind est une plateforme web interactive de sensibilisation à la cyberdépendance et à l’impact des réseaux sociaux sur le cerveau humain. Le site combine pédagogie, gamification et outils pratiques afin d’aider les utilisateurs à comprendre comment les algorithmes capturent leur attention et comment retrouver un équilibre numérique sain.
